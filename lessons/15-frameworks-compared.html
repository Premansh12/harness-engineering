Frameworks compared

Don't become dependent on a framework — but understand how each implements the harness concepts. This module compares the major SDKs on the axes that matter (tool execution, memory, planning, runtime loop, state) and says when to use which.

Section 1The warning, first

The roadmap you started from lists eight frameworks (OpenAI Agents SDK, LangGraph, AutoGen, CrewAI, Semantic Kernel, Microsoft Agent Framework, DSPy, LlamaIndex). The caution is the same as Module 09's: frameworks encode assumptions about model weakness that expire. Use them to move fast; don't mistake their defaults for truth; and keep the walkthe-loop skill (Module 01) so you can leave any of them.

Section 3Four representative SDKs

OpenAI Agents SDK
Lightweight, Python-first. Strong on tool-calling loop + handoffs (subagents). Good default if you're already on OpenAI and want minimal scaffolding.
LangGraph
Graph-shaped control flow. Explicit state and edges — you own the loop precisely. Best when you need deterministic, inspectable trajectories (Module 12).
Microsoft Agent Framework
Batteries-included harness (Module 00's Microsoft doc): compaction, todo, file memory, OTEL, shell, background agents — all toggleable. Closest to a "shipped harness."
CrewAI / AutoGen
Multi-agent orchestration first (Module 06's boundary). Role-based crews / conversation patterns. Use when the problem is coordination, not single-agent runtime.
DSPy
Programs-as-modules with compiled prompts. Different axis — optimizes the prompt/program, not the runtime. Complementary to harness work.
LlamaIndex
Data/retrieval-centric. Strong on the context-engineering (Module 03) and RAG side; harness features are narrower.

Section 4When to use which

If your problem is…Lean toward…
A custom single-agent runtime you fully controlLangGraph, or hand-rolled (Module 01)
Fast start on OpenAI, minimal codeOpenAI Agents SDK
Want a shipped harness with togglesMicrosoft Agent Framework
Many roles coordinatingCrewAI / AutoGen (orchestration)
Retrieval-heavy contextLlamaIndex
Prompt/program optimizationDSPy (complementary)

The single most important habit: keep the twelve-line loop in your head. Every framework is a decoration on it. When a framework's default fights a lesson in this course (e.g. its compaction is irreversible, or its verification is inside the loop), that's a signal to override it, not to trust it.
